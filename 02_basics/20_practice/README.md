# Ejercicios de Práctica - Go Bootcamp

Esta carpeta contiene ejercicios prácticos organizados por nivel de dificultad para practicar todos los conceptos aprendidos en el bootcamp de Go.

## Estructura de Práctica

### 📚 01_beginner/

Ejercicios básicos que cubren:

- Variables y tipos de datos
- Operadores aritméticos y lógicos
- Constantes y convenciones de nombres
- Condicionales básicos
- Bucles simples

### 🔧 02_intermediate/

Ejercicios intermedios que cubren:

- Arrays, slices y maps
- Funciones básicas y múltiples valores de retorno
- Range y manipulación de datos
- Control de flujo más complejo
- Manejo básico de errores

### 🚀 03_advanced/

Ejercicios avanzados que cubren:

- Funciones variádicas
- Defer, panic y recover
- Init y exit
- Manejo avanzado de errores
- Patrones de diseño básicos

### 🏆 04_final_project/

Proyecto final que integra todos los conceptos aprendidos en una aplicación completa.

## Instrucciones

1. **Comienza con el nivel beginner** y avanza secuencialmente
2. **Lee cuidadosamente cada enunciado** en los comentarios del código
3. **Implementa la solución** en el espacio proporcionado
4. **Compila y ejecuta** tu código para verificar que funciona
5. **Compara con las mejores prácticas** aprendidas en la teoría

## Consejos

- 💡 Si te atascas, revisa los ejemplos en la carpeta `02_basics/`
- 📖 Consulta la documentación en `00_theory/` para repasar conceptos
- 🧪 Experimenta con diferentes enfoques
- ✅ Asegúrate de que tu código compile sin errores
- 📝 Usa nombres descriptivos para variables y funciones

## Evaluación

Cada ejercicio tiene:

- **Descripción clara** del problema a resolver
- **Ejemplos de entrada y salida** esperados
- **Pistas** para guiar la implementación
- **Criterios de éxito** para verificar la solución
